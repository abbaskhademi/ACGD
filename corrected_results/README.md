# Corrected Benchmark Results

This directory contains the numerical results generated by the benchmark experiments in [**ACGD**](https://github.com/abbaskhademi/ACGD/tree/main).

Each subfolder corresponds to a specific optimization problem or benchmark experiment.

## Directory Structure

Each benchmark folder may contain the following files and subdirectories:

| File or folder | Description |
|---|---|
| `instances/` | Individual benchmark instances used in the experiment, typically stored as `.mat` files and identified by their seed numbers. |
| `*_iterations_*.mat` | Iteration histories produced by the different optimization methods. |
| `benchmark_all_methods.mat` | Aggregated benchmark data for all tested methods. |
| `profile_statistics.mat` | Statistics used to generate and analyze performance profiles. |
| `*_performance_profile_all_methods.png` | PNG image of the performance profile comparing the tested methods. |
| `*_performance_profile_all_methods.eps` | EPS version of the performance profile. |
| `*_report.txt` | Text report containing benchmark results and performance summaries. |
| `run_manifest.toml` | Metadata describing the benchmark configuration and execution settings. |

## Benchmark Results

The subdirectories contain the results for the corresponding numerical experiments. For example:

- `lasso/` — Results for the Lasso problem.
- `Sigmoid_w8a/` — Results for sparse least-squares sigmoid regression.

Other benchmark folders follow the same general organization where applicable.

## Notes

- MATLAB `.mat` files contain numerical data and benchmark outputs.
- Performance profile figures provide visual comparisons between optimization methods.
- The run manifest records relevant experiment settings to support reproducibility.
- Not every benchmark folder necessarily contains every file listed above.
